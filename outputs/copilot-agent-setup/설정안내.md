# Copilot Studio 업데이트 적용

새 동작: DB에 없는 부품 → 검색 에이전트 조사 → CreateComponent로 미검증 부품 ID 저장 → 이미지 에이전트 SVG 저장·적용 → 회로에서 사용 → 같은 DB에서 재사용.
자세한 안내는 프로젝트 COMPONENT_PIPELINE_SETUP.md를 참고한다.

1. 중앙 설계 안내: circuit-coordinator-instructions.md. 기술: circuit-coordinator-skill.zip. 지식: circuit-coordinator-knowledge.md.
2. 부품 검색·조사 안내: component-research-instructions.md. 기술: component-research-skill.zip. 지식: component-research-knowledge.md.
3. 이미지 안내: component-image-instructions.md. 기술: component-image-skill.zip. 지식: component-image-knowledge.md.
4. 회로 설계·검증 해석은 연결을 유지하고 새 공통 지식 파일로 교체한다.
5. 기존 MCP CircuitAgent를 새로 고쳐 신규 CreateComponent를 중앙·검색 에이전트에 활성화한다. 현재 총 20개다.
6. 검색 에이전트에서 웹 검색을 사용할 수 있도록 설정한다. 이미지 에이전트에 웹 검색이나 OpenAI 키를 추가할 필요는 없다.
7. 기존 '없으면 상태만 반환', '승인될 때까지 그림/초안도 중단', '초기 부품 목록에 없는 ID 금지' 지침을 새 안내로 교체한다.
8. 필요한 전문 에이전트가 중앙에 연결돼 있는지 확인하고 변경 사항을 게시한다. 연결 설명은 COMPONENT_PIPELINE_SETUP.md에 있다.
9. 웹사이트 Ctrl+F5 후 테스트한다. Studio 테스트에서 만든 그림은 미르의 서버 다시 연결로 불러온다.

서버 주소와 기존 인증 키는 유지한다. .env, 키, DB, 로그는 지식으로 올리지 않는다.
이 자료 생성은 실제 Studio 업로드·게시를 대신 실행한 것이 아니다.
