Copilot Studio 에이전트 연결

새 에이전트는 웹사이트 링크로, 클래식 에이전트는 Direct Line으로 연결합니다. 연결 안내

Microsoft 채팅을 화면에 표시합니다. 답변 자동 해석과 현재 배선 자동 전송은 지원하지 않습니다. 회로 ID로 DB를 불러오세요.
앱에서는 Windows 암호화로 저장합니다. 브라우저에서는 이 탭을 닫으면 키가 지워집니다. 공유 서버 PC가 켜져 있어야 합니다.

Direct Line 비밀 키는 Python 서버만 읽습니다. 브라우저에는 입력하지 않습니다. 채팅은 기존 미르 화면을 사용합니다.
이 PC에 암호화되어 저장되며, 다른 곳으로 보내지 않습니다.

데이터시트로 부품 만들기

데이터시트의 핀 배치표·전기적 특성 부분을 복사해 붙여 넣으면, AI 에이전트가 부품 JSON을 만들어 줍니다. 확인 후 저장하면 부품함에 추가됩니다. 본인이 가진 자료만 사용하세요.

배선 API · DB

Copilot Studio가 만든 회로 ID를 불러오거나 현재 배선을 저장합니다. 로컬 .env 또는 연결 설정의 공유 서버를 사용합니다.

API 연결 전

미르 기본 부품은 화면용 자료입니다. 부품 DB에 없으면 초안 저장은 가능하지만 서버 검증에서 미등록 오류가 납니다. 가상 전원 결과와 서버 검증은 별개입니다.

KiCad 파일 검증

별도로 만든 회로도와 모델 파일을 가져옵니다. 현재 미르 배선의 검증 상태는 변경하지 않습니다.
