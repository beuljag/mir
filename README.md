# 미르 V95

이 저장소의 main은 V95 관련 파일만 보관합니다.

- [Windows V95 EXE 다운로드](https://github.com/beuljag/mir/releases/download/v95/mir-V95.exe)
- [V95 사용 안내](V95/README.md)
- [미르 HTML](V95/미르%20HTML/미르%20HTML.html): V95 폴더를 내려받은 뒤 HTML 파일을 직접 엽니다.
- [개발 소스](V95/개발소스): V95 Windows 앱 소스와 연결 서버, 빌드·검사 도구를 보관합니다.

HTML을 실행할 때는 `V95/미르 HTML` 폴더 전체를 함께 보관하세요. AI·DB는 별도 서버 연결이 필요합니다. API 키는 저장소에 포함하지 않습니다.

앱 개발·서버 실행 명령은 `V95/개발소스` 폴더에서 실행합니다. [개발 안내](V95/개발소스/README.md)와 [Windows·Linux 서버 실행 안내](V95/개발소스/docs/공유-서버-연결.md)를 참고하세요.

이전 버전 실행 파일·변경 기록·초기 협업 템플릿은 main에서 제거했습니다. 이전 커밋과 기존 릴리스는 변경하지 않았습니다.
