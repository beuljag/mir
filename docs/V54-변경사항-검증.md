| 번호 | 문제 | 수정 결과 |
|---|---|---|
| 1 | 확인창 뒤에서 단축키가 회로를 변경함 | 확인창이 열려 있을 때 제작판 편집 단축키 차단. 입력창과 팝업별 단축키 범위 분리. |
| 2 | 손상된 프로젝트를 열면 오류만 발생하고 작업 화면이 깨짐 | 반영 전 참조·부품·핀·좌표·연결을 검사하고 실패하면 기존 작업과 저장 경로 보존. |
| 3 | 연결 설정 읽기 실패 시 아무 안내 없이 설정이 열리지 않음 | 설정 읽기 예외 표시, 재시도와 안전한 기본 입력 제공. |
| 4 | AI 수정안 적용 버튼이 도구 모음에 가려져 눌리지 않음 | 미리보기 바를 도구 모음 아래에 두고 높이·여백·채팅 위치 갱신. |
| 5 | 새 프로젝트와 파일 열기에 이전 되돌리기 기록이 남음 | 새 프로젝트·다른 파일 열기 시 프로젝트 단위로 history/future 초기화하고 선택·팝업 상태 정리. |
| 6 | 드래그 중 창 포커스를 잃으면 드래그가 끝나지 않을 수 있음 | 창 포커스 상실·pointercancel·버튼 해제에 드래그와 예약 프레임을 정리하고 최종 상태 확정. |
| 7 | AI 수정안 적용이 바뀌지 않은 선의 수동 색상도 지움 | 양 끝 핀이 같은 기존 선의 사용자 색상·식별 정보를 유지하고 변경된 연결만 갱신. |
| 8 | 배선 API·DB 기능으로 들어갈 보이는 메뉴가 없음 | 삭제한 상단 버튼을 다시 만들지 않고 파일 또는 도구 메뉴에 DB 진입점 추가 제안. 위치는 승인 후 결정. |
| 9 | 대화창을 넓히면 선 색상/자동 연결 선택기를 가림 | 선택기를 대화창을 제외한 사용 가능한 영역에 배치하고 최소 크기·메뉴 접힘 상태 반영. |
| 10 | 저장된 데모 모드가 재실행 시 서버 모드로 바뀔 수 있음 | 사용자가 저장한 데모 선택을 존중하고, 초기 자동 감지 여부를 별도로 구분. |
| 11 | 부품 속성창에서 Esc를 누르면 빈 창이 남음 | Esc는 속성창 전체를 닫고 뒤쪽 선택 해제와 충돌하지 않도록 분리. |
| 12 | 작업 창을 줄이면 이동한 속성창이 화면 밖으로 나감 | 창 크기 변경·팝업 크기 변경·열기 시 좌표를 보이는 영역으로 보정. |
