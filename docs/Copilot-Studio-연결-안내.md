# Copilot Studio 에이전트를 프로그램에 연결하기

프로그램은 Copilot Studio 에이전트와 **Direct Line**으로 대화합니다. 아래 두 방법 중 하나를 고르세요.
처음이면 **방법 A**가 가장 쉽습니다.

## 0. 공통 준비

1. https://copilotstudio.microsoft.com 에서 에이전트를 엽니다.
2. **개요 > 지침**에 `Copilot-Studio-지침.md`의 내용을 붙여 넣습니다.
3. 오른쪽 위 **게시(Publish)** 를 누릅니다. 게시하지 않으면 바뀐 내용이 프로그램에 반영되지 않습니다.

## 방법 A. Direct Line 비밀 키 (웹 채널 보안)

1. 에이전트 **설정(Settings) > 보안(Security) > 웹 채널 보안(Web channel security)** 으로 갑니다.
2. **비밀 1(Secret 1)** 의 `복사`를 누릅니다.
3. 프로그램 오른쪽 위 **⚙ → "Direct Line 비밀 키"** 를 고르고 붙여 넣은 뒤 **연결 테스트**를 누릅니다.

- 키는 이 PC에만 암호화되어 저장됩니다. 키를 다른 사람에게 보내거나 깃허브에 올리지 마세요.

**⚙ 대신 `.env` 파일로 넣기**

1. `.env.example`을 복사해 이름을 `.env`로 바꿉니다. (`.exe`로 실행할 때는 `.exe`와 같은 폴더에 둡니다.)
2. `COPILOT_DIRECT_LINE_SECRET=` 뒤에 복사한 키를 **큰따옴표 없이, 띄어쓰기 없이 바로** 붙여 넣고 저장합니다.

   ```
   COPILOT_DIRECT_LINE_SECRET=AbCdEf123.gHiJkL456-mNoPqR789
   ```

   ❌ `COPILOT_DIRECT_LINE_SECRET="AbCdEf123..."` 처럼 큰따옴표로 감싸지 마세요.
3. 프로그램을 다시 켭니다. ⚙에서 저장한 키가 있으면 그 키가 먼저 쓰입니다.

- `.env`는 `.gitignore`에 들어 있어 깃허브에 올라가지 않습니다. `.env.example`에는 진짜 키를 넣지 마세요.
- 학교/기관 계정에서 이 메뉴가 안 보이면 관리자가 막아 둔 것입니다. 방법 B를 쓰거나 지도교사께 문의하세요.

## 방법 B. 토큰 끝점 URL (인증 없음)

1. 에이전트 **설정 > 보안 > 인증(Authentication)** 에서 **인증 없음(No authentication)** 을 고르고 저장, 게시합니다.
   (누구나 이 에이전트와 대화할 수 있게 되므로 수업·대회용 에이전트에만 쓰세요.)
2. **채널(Channels) > 모바일 앱(Mobile app)** 에서 **토큰 끝점(Token Endpoint)** URL을 복사합니다.
3. 프로그램 **⚙ → "토큰 끝점 URL"** 에 붙여 넣고 **연결 테스트**를 누릅니다.

## 방법 C. 미르 토큰 서버 (.exe 배포용, 추천)

`.exe`를 다른 사람에게 나눠 줄 때는 비밀 키를 앱에 넣지 말고 **토큰 서버**를 쓰세요.
서버 실행·호스팅·`app-config.json` 설정은 `server/README.md`를 보세요.
⚙에서 고를 때는 **"미르 서버 / 토큰 끝점 URL"** 에 서버 주소(`https://내서버주소`)를 넣습니다. `/token`은 앱이 자동으로 붙입니다.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| `Direct Line 오류 403` | 비밀 키가 틀렸거나 다시 생성됨 → 새로 복사 |
| `토큰 발급 실패 (401/403)` | 인증 없음으로 게시되지 않음 → 인증 설정 확인 후 게시 |
| `에이전트 응답 시간이 초과되었습니다` | 에이전트가 오래 생각함/오류 → Copilot Studio 테스트 창에서 같은 질문 해 보기 |
| 답은 오는데 그림이 안 그려짐 | 지침의 JSON 형식이 빠짐 → 지침을 다시 붙여 넣고 게시 |
| "부품함에 없는 부품" 경고 | 에이전트가 목록에 없는 id를 씀 → 부품 JSON 추가 또는 지침의 [부품 목록] 규칙 강조 |

## 데모 모드

연결 전에도 **데모 모드**로 정해진 예시(밸브 제어, 온도→OLED, LED, 라즈베리파이 LED)를 체험할 수 있습니다.
