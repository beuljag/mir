# 미르 전체 변경사항

작성일: 2026-11-02 · 정리 기준: 현재 대화의 요청·수정 기록과 로컬 통합·검사 기록

이 문서는 로고 적용부터 V21까지 함께 진행한 변경을 정리합니다. 최종 적용 상태와 중간에 변경된 방향, 검사 범위를 구분합니다. 초기 작업은 V 번호가 확정되지 않았으므로 임의로 V1~V18 번호를 붙이지 않았습니다.

## 1. 버전 흐름

| 단계 | 주요 내용 |
|---|---|
| 초기 로고·비주얼 작업 | 미르 로고 배경 투명화, 앱 아이콘 적용, 실행 파일·소스 제공 |
| floating-workspace 수정 | 메뉴, 떠 있는 부품함·에이전트 창, 배선 정렬과 표시 방식 개선 |
| 최신 기본 버전과 통합 | 기존 UI 수정을 유지하면서 부품 속성·저장·시뮬레이션 기능 통합 |
| V19 | 최신 공유 서버 브랜치 통합, UX 분석·수정, 종료 오류 수정 |
| V20 | 설정에 메인 색상 탭 추가 |
| V21 | 최신 GitHub main의 로고 자산을 반영하고 기존 기능을 유지해 재빌드 |

## 2. 로고와 앱 아이콘

- 제공받은 미르 로고를 앱의 시각적 기준으로 사용했습니다.
- 로고 배경을 투명하게 처리하고 창·상단 로고·실행 파일에 적용했습니다.
- V21에서는 GitHub 최신 main의 `build/icon.png`, `build/icon.ico`로 갱신했습니다.
- 최신 저장소에 있는 테스트 EXE를 그대로 사용한 것이 아니라, 통합 소스로 실행 파일을 새로 만들었습니다.

## 3. 메뉴와 작업 공간

- 메뉴 버튼을 가장 왼쪽, 미르 로고 앞에 배치했습니다.
- 메뉴에 새로 만들기, 열기, 저장, 다른 이름으로 저장을 넣었습니다.
- 메뉴 하단에 다크/라이트 모드와 설정 진입 버튼을 배치했습니다.
- 메뉴를 열고 닫을 때 간단한 애니메이션을 추가했습니다.
- 작업판은 넓게 사용하고, 부품이 상단 도구 모음 뒤까지 배치될 수 있게 했습니다.
- 상단의 길고 둥근 도구 모음 자체는 유지했습니다.

## 4. 부품함과 부품 정보

- 왼쪽의 상시 목록을 접고, 왼쪽 아래 트랜지스터 모양 버튼으로 부품함을 열게 했습니다.
- 부품함 열기·닫기 애니메이션을 추가했습니다.
- 상단·오른쪽·모서리를 이용해 부품함 크기를 조절하고 크기를 저장합니다.
- 크기 조절 핸들은 키보드 방향키도 지원합니다.
- 부품 검색, 분류, 최근 부품과 분류 접기 기능을 유지했습니다.
- 분류 버튼이 가로 스크롤 대신 여러 줄로 배치되도록 했습니다.
- 선택한 부품 설명을 에이전트 창 옆 하단에 배치해 가려지지 않도록 했습니다.
- 핀·전선 툴팁이 에이전트 창, 접힌 입력창, 답변 말풍선, 접기 버튼을 피해 표시되도록 했습니다.

## 5. 에이전트 대화창

- 작업판 위에 떠 있는 둥근 대화창으로 배치했습니다.
- 접기 버튼을 펼친 창 오른쪽 위에 놓고, 접힌 상태에서는 입력창 오른쪽 위 바깥에 표시했습니다.
- 접으면 오른쪽 아래에 입력칸과 전송 버튼만 남도록 했습니다.
- 접기·펼치기 및 새 메시지가 아래에서 올라오는 애니메이션을 추가했습니다.
- 입력칸을 사용자가 세로로 늘리는 기능은 제거했습니다.
- 대화창이 상단 도구 모음과 하단 안내 바에 겹치지 않도록 여백을 계산합니다.
- 접힌 상태에서도 AI 답변을 입력창 위 별도 말풍선으로 표시합니다.
- 말풍선을 닫아도 원래 대화 기록에는 답변이 남습니다.
- 입력·스크롤 등 에이전트 창 조작이 뒤쪽 작업판에 전달되지 않도록 했습니다.
- 요청 처리 중 중복 전송·진단으로 입력이 지워지는 문제를 막았습니다.
- 호출 실패를 접힌 창에서도 확인할 수 있고, 입력칸이 비어 있으면 원래 요청 문구를 복구합니다.
- 프로젝트를 바꾼 뒤 이전 요청의 답변이 새 작업에 적용되지 않도록 구분합니다.

**최종 투명도:** 중간에 약 50% 투명도를 적용했지만 이후 요청에 따라 제거했습니다. 현재 에이전트 창과 답변 말풍선은 불투명합니다.

## 6. 배선 알고리즘과 표시

- 직선 모드에 장애물 회피와 정렬을 위한 라우팅 알고리즘을 적용했습니다.
- 핀의 방향, 부품 경계, 경로 길이, 굽힘, 교차·겹침 비용을 고려합니다.
- 여러 선의 긴 겹침을 줄이기 위해 경로 간격을 고려합니다.
- 지나친 우회로 연결 위치가 혼동되지 않도록, 우회가 과도하면 기본 경로를 유지하도록 보완했습니다.
- 직선 모드도 모서리를 약간 둥글게 마감합니다.
- 짧은 선이나 거의 같은 높이의 핀을 연결할 때 작은 계단 모양으로 꺾이는 현상을 보완했습니다.
- 짧은 곡선이 핀 바깥으로 되돌아가는 문제도 보완했습니다.
- 겹침은 선 전체의 점선·색 변경으로 표시하지 않고, 길게 겹치는 부분에만 밝기 차이를 표시합니다.
- 경로를 정리할 때 연결의 출발·도착 핀 자체는 변경하지 않습니다.
- 기본 곡선 모드는 GitHub 원본의 처지는 곡선 표현을 유지합니다.
- 메뉴 → 설정에서 곡선/직선 토글, 선택 상태 저장, 시각적 미리보기를 제공합니다.
- 초기 배선 AI 적용 안내 MD를 작성하고 관련 설명·검사 기록을 제공했습니다.

**표현상 주의:** 사용 과정에서는 원본 곡선을 ‘현수선’이라고 불렀지만, 구현은 원본 스타일의 SVG 곡선입니다. 모든 배치에서 교차·겹침을 완전히 없애는 알고리즘은 아닙니다.

## 7. 부품 속성과 파일 작업

- 부품별 LED 색상·순방향 전압, 저항값 변경 기능을 통합·유지했습니다.
- 변경된 값이 부품 그림·표시와 시뮬레이션에 반영되도록 했습니다.
- 로컬 JSON 파일에 부품 속성을 저장하고 다시 불러옵니다.
- 저장·다른 이름으로 저장 및 저장 취소·실패 처리를 유지했습니다.
- 저장 성공을 알리고, 저장 도중 추가로 편집한 내용은 미저장 상태로 남깁니다.
- 미저장 작업이 있을 때 새로 만들기·파일 열기·종료 전에 확인합니다.
- 빈 데이터시트 입력과 부품 파일 가져오기 실패 안내를 보완했습니다.

## 8. V19 공유 서버 기능 통합

- `feat/shared-tunnel-client`의 `8b5c1bf`를 기존 Electron UI와 통합했습니다.
- 기존 채팅 UI에서 공유 서버의 비동기 대화와 진행 상태를 사용합니다.
- 진행 안내를 최종 응답으로 오인하지 않는 최신 서버 처리를 포함했습니다.
- 회로 DB 불러오기, 버전 기반 저장, 서버 배선 검증 기능을 추가했습니다.
- 부품 조사·이미지 결과 갱신과 서버 이미지의 핀 좌표 사용을 통합했습니다.
- Microsoft 웹 채팅 모드와 별도 웹사이트 열기를 추가했습니다.
- KiCad 파일·폴더 가져오기와 검사 요청·작업 상태 조회 UI를 통합했습니다.
- Python FastAPI·MCP·조사·이미지·채팅 서버 소스를 포함했습니다.
- LED/저항 속성과 역할 문구를 DB에도 보존하기 위해 선택적 `props`, `label` 필드를 추가했습니다.
- API 명세를 다시 생성했습니다. 이 추가 필드를 DB에 저장하려면 서버도 통합 소스로 업데이트해야 합니다.

클라이언트 EXE에 Python 서버·KiCad·ngspice 실행 프로그램을 내장한 것은 아닙니다. 공유 서버 사용에는 서버 주소와 배선 API 키가 필요합니다.

## 9. UX 분석과 후속 수정

- 코드 기반 UX 프로필과 감사·재검사 보고서를 작성했습니다.
- 초기 전체 프로필은 13개 화면, 93개 상태를 기능별로 정리했습니다.
- 초기 감사의 일부 항목은 모든 동작에 오류 안내를 요구한 과잉 분류였습니다. 그 수치를 실제 실행 오류 개수로 해석하지 않습니다.
- 후속 부분 재검사의 7개 항목에 대해 삭제 확인, 초기화 실패·재시작 안내, DB 저장 기준, 실패 입력 복구, 설정 테스트 문구, DB 상세 결과, KiCad 결과 요약·접힌 상세 표시를 보완했습니다.
- 서버 테스트 편집기의 회로 교체·초안 반영과 후보 반려에도 확인을 추가했습니다.

### 닫기 버튼 오류 원인과 해결

미저장 보호용 `beforeunload`가 종료를 막는데, Electron 메인에 `will-prevent-unload` 확인 처리가 없어 창이 닫히지 않았습니다. 메인에서 ‘계속 편집’과 ‘저장하지 않고 종료’를 선택하도록 수정했습니다. 개발 앱과 패키지에서 취소 시 창 유지, 종료 선택 시 실제 종료를 확인했습니다.
