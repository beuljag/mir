# 배선 API 연결

이 로컬 브랜치에는 Python 배선 API와 미르를 연결하는 기능이 추가되어 있다.
상단 **배선 API · DB**에서 자동 연결 상태를 확인하고 회로 ID를 입력해 불러온다. 키는 입력하지 않는다.
화면을 수정한 뒤 **현재 화면 DB 저장**, **서버 검증** 순서로 실행한다.

브라우저에서는 미르를 제공하는 같은 서버에 연결하고, Electron에서는 `http://127.0.0.1:8000`에 연결한다.
기존 **연결 설정**의 Direct Line은 채팅용이며, 배선 DB의 API 키와 다르다.
키는 Python 서버의 `.env`에서 관리한다. 이 PC 전용 8002번 연결이 인증을 대신 처리하며 키를 화면에 전달하지 않는다. Git에 넣지 않는다.

부품함의 기본 자료는 검증된 DB 사양이 아니다. DB에 없는 부품의 초안은 저장할 수 있어도 서버 검증에서 오류가 난다.
에이전트 최종 응답에 `{"type":"circuit_reference","circuit_id":"저장된 ID"}` JSON 코드블록이 있으면 DB 불러오기 버튼을 표시한다.
더 자세한 안내는 상위 Python 프로젝트의 `MIR_SETUP.md`를 참고한다.
