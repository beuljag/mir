# 최신 미르 통합 기록

기준: https://github.com/beuljag/mir/commit/ff9401f481dcb75444982ba0cf7b6b40e2761cd1

기존 수정본 D:\TEST\mir-floating-workspace는 수정하지 않고 보존했다. 최신 저장소를 D:\TEST\mir-latest에 별도로 받아 공통 원본 c089711을 기준으로 3방향 병합했다.

최신 기능: 부품별 LED 색상·순방향 전압, 저항값 편집 및 저장, props가 시뮬레이션과 AI 요청에 전달됨. .env/app-config 서버 설정과 기본 부품 그림 복원을 유지했다.

보존 기능: 직각 배선 라우터, 경로 캐시, 메뉴와 다크/라이트 전환, 저장/다른 이름 저장, 떠 있는 크기 조절 부품함, 반투명 에이전트 패널, 접기 버튼 및 축소 응답 말풍선, 메시지 애니메이션, 상하단 바 간격, 부품 설명 위치.

통합 추가 수정: 핀/전선 툴팁이 에이전트 패널·축소 입력창·답변 말풍선·접기 버튼을 피해 배치됨.

검증: 자동 테스트 17개 통과. 개발 앱 및 패키징 앱에서 기존 화면 기능, 부품 속성 편집, props 저장/열기, 툴팁 비겹침 검사. 검사에서 에이전트 응답과 시스템 파일 선택창은 대체했으며 외부 Copilot 서버 통신은 검증하지 않았다.

범위: 이번 작업은 최신 버전과 기존 수정본의 통합이다. 앞선 배선 진단의 교차 비용, 입력 검증, 탐색 성능 등 전체 개선이 완료되었다는 뜻은 아니다. 기존 라우터의 알려진 한계는 남아 있다. 별도의 알고리즘 수정과 회귀 검증이 필요하다.

커밋/푸시/PR 생성 없음. GitHub 최신 기본 부품 그림 변경을 존중하므로 이전 SVG 기본 선택은 복원하지 않았다.
