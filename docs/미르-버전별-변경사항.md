# 미르 버전별 변경사항

정리일: 2026-11-02

각 버전에서 새로 추가하거나 수정한 내용만 정리했습니다. 이전 버전의 기능은 다음 버전에도 유지됩니다. 대화에서 버전 번호를 확정한 것은 V19부터이며, 초기 작업에 임의로 V1~V18 번호를 붙이지 않았습니다.

## 버전 번호 지정 전

### 로고·아이콘

- 제공된 미르 로고의 배경을 투명하게 처리하고 앱 아이콘에 적용.
- 실행 파일과 소스 패키지 제공.

### 작업 공간·메뉴

- 가장 왼쪽에 메뉴 버튼 배치.
- 새로 만들기·열기·저장·다른 이름으로 저장 메뉴 추가.
- 메뉴 하단 다크/라이트 모드 및 설정 버튼 배치.
- 메뉴 열기·닫기 애니메이션 추가.
- 작업판을 넓히고 부품이 상단 도구 모음 뒤까지 배치되도록 변경.

### 부품함

- 왼쪽 아래 트랜지스터 모양 버튼으로 여는 부품함 추가.
- 부품함 열기·닫기 애니메이션과 자유로운 크기 조절 추가.
- 선택 부품 설명을 에이전트 옆 하단에 배치.
- 핀·전선 툴팁이 에이전트와 겹치지 않도록 위치 계산 보완.

### 에이전트

- 둥근 떠 있는 대화창 및 접기·펼치기 추가.
- 접힌 상태에서 입력칸·전송 버튼과 별도 답변 말풍선 제공.
- 새 메시지와 창 접기·펼치기 애니메이션 추가.
- 입력칸 수동 크기 조절 제거.
- 상단·하단 바와 겹치지 않도록 간격 조절.
- 중간에 적용한 반투명 효과는 이후 요청에 따라 제거.

### 배선

- 직선 모드에 장애물 회피·정렬 알고리즘 적용.
- 선 사이 간격과 과도한 우회를 고려하도록 보완.
- 직선 모서리를 둥글게 처리하고 짧은 선의 계단·되돌아감 현상 보완.
- 겹치는 구간에만 밝기 차이를 주도록 변경.
- 원본 스타일의 처지는 곡선을 기본으로 설정.
- 곡선/직선 토글과 시각적 미리보기 추가.
- 배선 알고리즘 적용 안내 MD 작성.

## V19 — 최신 서버 기능 통합

### 최초 V19에 추가한 기능

- GitHub `feat/shared-tunnel-client`의 `8b5c1bf` 변경 통합.
- 공유 서버를 통한 비동기 채팅과 진행 단계 표시.
- 진행 안내 메시지와 최종 응답을 구분하는 서버 처리.
- 회로 DB 불러오기·버전 기반 저장·서버 배선 검증.
- 부품 조사·이미지 결과 갱신 및 서버 이미지의 핀 좌표 사용.
- Microsoft 웹 채팅 모드와 별도 웹사이트 열기.
- KiCad 파일·폴더 가져오기 및 검사 요청·상태 조회 UI.
- Python FastAPI·MCP·조사·이미지·채팅 서버 소스 포함.
- 부품 속성·역할 문구를 DB에도 보존하는 선택적 `props`, `label` 필드 추가.
- 부품 분류 버튼이 가로 스크롤 대신 여러 줄로 배치되도록 적용.
- 버전별 폴더 배포 시작.

### V19 UX 개선판에서 수정한 내용

- 미저장 작업이 있을 때 새로 만들기·파일 열기·종료 전 확인.
- 저장 성공 안내 및 저장 중 추가 편집의 미저장 상태 유지.
- AI 요청 중 중복 전송·진단으로 입력이 지워지는 문제 방지.
- 접힌 채팅에도 호출 실패 안내 표시.
- 프로젝트를 바꾸면 이전 AI 답변이 새 작업에 적용되지 않도록 처리.
- 빈 데이터시트 입력과 부품 가져오기 실패 안내 보완.
- 서버 테스트 편집기의 회로 교체·초안 반영, 후보 반려에 확인 추가.

### V19 닫기 오류 수정판에서 추가로 수정한 내용

- 종료를 막기만 하던 저장 보호를 수정하고 ‘계속 편집 / 저장하지 않고 종료’ 확인창 추가.
- 선택한 부품·전선을 삭제하기 전 확인.
- 초기화 실패 안내와 다시 시작 버튼 추가.
- DB 회로를 불러온 뒤 저장 기준 갱신.
- AI 전송 실패 시 입력칸이 비어 있으면 원래 요청 문구 복구.
- 연결 테스트 버튼을 ‘저장하고 연결 테스트’로 변경.
- DB 검증 상세 결과를 DB 창 안에서도 표시.
- KiCad 결과를 요약하고 상세 JSON은 접어서 제공.

### 제공 파일

- 최초 통합본: `V19/mir-V19.exe`
- UX 개선판: `V19/mir-V19-ux.exe`
- 닫기 오류 수정판: `V19/mir-V19-close-fixed.exe`
- 각 수정판의 소스 ZIP·검사·변경 기록.
