## 서버 관리자

소스 ZIP에는 app/, scripts/, requirements.txt 및 각 SETUP 문서가 포함되어 있습니다. 기존 DB·키·.env는 배포 파일에 넣지 않았습니다. 기존 서버 데이터는 백업 후 이 통합 소스로 서버를 업데이트하세요. 자동 시작 등록이나 외부 서버 배포는 수행하지 않았습니다.

LED 색·저항값·역할 문구를 DB에도 보존하도록 ComponentInstance에 선택적 props/label을 추가했습니다. 이 값을 DB에 저장하려면 서버도 함께 업데이트해야 합니다. 예전 서버가 이 필드를 거부하면 로컬 JSON 파일로 먼저 저장하세요. 배포용 API 명세도 재생성했습니다. 서버 사양 검증과 앱의 간이 시뮬레이션은 검사 범위가 서로 다릅니다.

requirements-integrated-tested.txt는 이번 검사 환경의 의존성 목록입니다. Windows Python 3.12로 검사했습니다. 공유 서버 클라이언트 EXE는 Python 서버·KiCad·ngspice를 내부 실행 파일로 포함하지 않습니다.
