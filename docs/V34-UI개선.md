# V34 UI개선

V21에 상단과 왼쪽이 연결된 작업 공간 메뉴를 적용했습니다. 접으면 64px 아이콘 메뉴, 펼치면 220px(좁은 창 180px) 메뉴가 표시됩니다. 제작판은 메뉴 옆으로 이동하며 오른쪽 에이전트 위치는 유지됩니다.

- 새 프로젝트·제작판·앱 설정·에이전트 연결 메뉴와 프로젝트 열기·저장
- 메뉴 및 새 프로젝트 버튼 모션, 모션 줄이기 지원
- 메뉴 아이콘·배선 API · DB·연결 안내 검정색 고정
- 로고 설명 문구 제거
- 새 프로젝트·열기·삭제·DB 불러오기·종료 확인을 공통 미르 대화상자로 변경
- 확인창 확대·페이드 등장, 계속 편집 및 종료 동작
- 명시적으로 선택한 AI 연결 방식 보존

## 검증

패키징된 V34 앱의 팝업 등장·확인·취소·모션 줄이기 검사 통과. V33 실제 창 닫기 경로에서 계속 편집과 저장하지 않고 종료 확인. 메뉴 배치·반복 토글·두 창 너비 검사 통과. 채팅은 앱 IPC와 모의 서버 전송·폴링·응답 표시 검사 통과. 실제 외부 Copilot 답변 수신은 미검증입니다.

실행 파일과 로컬 설정·키는 PR에 포함하지 않습니다.
