# 팀원 PC에서 공유 배선 서버 사용

## 팀원이 할 일

1. 이 변경이 머지된 저장소를 받습니다. 소스 실행에는 Node.js LTS가 필요합니다. 완성된 exe를 받은 경우 Node.js는 필요 없습니다.
2. `미르실행.bat`를 실행합니다. 처음에는 `npm ci`로 Electron을 설치하고, 이후에는 바로 앱을 엽니다. Python 서버와 터널은 팀원 PC에서 실행하지 않습니다.
3. **연결 설정 → 서버 API → 공유 서버 (팀장 터널)**를 선택합니다.
4. 서버 주소는 기본 입력값을 사용합니다. 값이 없거나 바뀌었다면 서버 관리자가 전달한 HTTPS 주소를 입력합니다. `/mcp`, `/mir/`, `/docs`는 붙이지 않습니다.
5. 관리자가 별도로 전달한 **배선 API 키**를 입력하고 **연결 테스트**를 누릅니다. Direct Line 비밀 키를 입력하지 않습니다.
6. 성공하면 기존 미르 채팅에서 설계를 요청합니다. 부품 목록·이미지·회로 저장·검증도 같은 공유 서버를 사용합니다.

Windows 앱은 `userData/server-connection.json`에 배선 키를 Windows 암호화로 저장합니다. 다른 PC에 이 파일을 복사하지 마세요. 주소를 바꾸면 그 주소에 맞는 키를 다시 입력해야 합니다. 설정이나 키가 Git에 저장되지는 않습니다.

브라우저로 사용하는 경우 관리자가 알려준 `https://공유서버주소/mir/`를 엽니다. 공유 서버 모드에서 주소와 배선 API 키를 입력합니다. 키는 탭 메모리에만 보관하므로 새로고침하거나 탭을 다시 열면 다시 입력합니다. 브라우저에 Direct Line 비밀 키를 넣지 않습니다.

## 서버 관리자가 할 일

- 현재 서버 PC에서 기존 `서버켜기.bat`로 API와 고정 Dev Tunnel을 실행합니다. 팀원은 관리자의 터널 계정으로 로그인하지 않습니다.
- 서버 PC와 인터넷 연결이 유지되어야 합니다. 절전·전원 종료·터널 로그인 만료 동안에는 팀원도 사용할 수 없습니다.
- `config/tunnel.json`의 `public_url`을 팀원에게 전달합니다. 기본 공유 주소는 저장소의 `renderer/server-defaults.json`으로 배포됩니다. 이 파일에는 URL만 넣습니다.
- 기존 서버 `.env`의 `CIRCUIT_API_KEY`를 팀원에게 별도 채널로 전달합니다. Git·스크린샷·공개 문서에는 넣지 않습니다. Direct Line 비밀 키와 사람 검토 키는 전달하지 않습니다.
- 동일한 배선 API 키를 쓰는 팀원은 같은 소유자의 부품·회로 DB를 공유합니다. 개별 데이터 분리가 필요하면 서버에 별도 키와 소유자 매핑을 구성해야 합니다.
- 기존 Copilot Studio MCP는 현재 서버의 `/mcp` 주소를 계속 사용합니다. 팀원용 터널이나 MCP를 새로 만들 필요가 없습니다.

## 연결이 실패하면

- 401: 배선 API 키를 확인합니다.
- 연결 시간 초과·JSON 응답 오류: 서버와 터널이 켜져 있는지, 주소가 맞는지 관리자가 확인합니다. 재로그인은 서버 PC에서만 합니다.
- Direct Line 인증 오류: 관리자가 서버 `.env`의 Direct Line 비밀 키를 확인합니다.
- 로컬 서버로 돌아가려면 **서버 위치 → 이 PC의 서버**를 선택하고 저장합니다.

공유 서버 연결 시 API 키는 지정한 HTTPS 서버에만 보냅니다. HTTP 리디렉션은 따라가지 않습니다. KiCad/ngspice 검증 프로그램도 서버 PC에 설치되어 있어야 합니다.

## CircuitAgent 연결 필요 오류와 부품 생성 시간 초과

2026-10-29 실제 미등록 보드 요청에서 Copilot은 `Connection Required / CircuitAgent / Set up your connection, then select Retry` 카드를 반환했습니다. 이는 Direct Line 채팅 연결 성공과 별개인 도구 연결 요구입니다. 부품 생성 성공을 의미하지 않습니다.

- Copilot Studio에서 중앙 에이전트와 해당 도구를 호출하는 연결 에이전트의 **도구 → CircuitAgent**를 엽니다.
- 저장된 MCP 연결이 유효한지 확인합니다. 도구의 인증/사용할 자격 증명에 **Maker-provided credentials(제작자 제공 자격 증명)**를 선택할 수 있다면 현재 서버 API 키로 만든 제작자 연결을 선택하고 저장·게시합니다.
- 메뉴가 없거나 비활성화되어 있으면 인증 채널이나 환경 정책의 제한을 확인해야 합니다. 에이전트의 ‘인증 없음’을 임의로 바꾸면 기존 Direct Line 연결 방식에도 영향이 있으므로 먼저 도구 상세 설정을 확인합니다.
- 공식 문서: https://learn.microsoft.com/en-us/microsoft-copilot-studio/add-tools-custom-agent

클라이언트는 실패한 대화를 정리하고 다음 사용자 요청을 새 대화로 보냅니다. 기존 요청을 자동 재전송하지 않습니다. 서버 기본 대기 시간은 300초이며 `.env`의 `COPILOT_REPLY_TIMEOUT_SECONDS`에 30~900초를 지정할 수 있습니다. 카드 응답도 읽고, 연결 필요 카드에는 명시적 오류를 표시합니다. 대기 시간을 늘리는 것만으로 도구 연결 요구가 해결되지는 않습니다.
