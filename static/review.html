원문 모델·리비전·패키지별 핀·전기적 제한을 직접 대조한 뒤 승인하세요. 자동 발췌는 확정 사양이 아닙니다.

API 키는 config/local-api-keys.json, 별도 검토 키는 config/local-review-key.json에서 확인합니다. 검토 키를 에이전트에 등록하지 마세요.






검토 후 작성하는 부품 정의


빈 필드를 채우고 pins에 실제 확인한 핀을 작성하세요. 새 리비전은 새 id로 등록합니다. 기존 부품은 덮어쓰지 않습니다.
