그림으로 배우는 미르

처음이라면 예제를 하나 열어 보고, 빈 제작대에서 직접 부품 두 개를 연결해 보세요. 각 단계에 마우스를 올리거나 Tab 키로 그림에 초점을 옮기면 시범이 재생돼요.

1. 시작2. 부품3. 배선4. 이동과 편집5. 가상 전원6. 저장7. AI 에이전트
01

LED 예제 열기

  1. 빈 제작대에 보이는 그림 카드 세 개 중 맨 오른쪽 ‘LED 깜빡이기’를 클릭하세요.
  2. 제작대에 라즈베리파이, 저항, LED가 선으로 연결된 상태로 열려요.
  3. 회로가 한눈에 안 보이면 위쪽 맞춤을 눌러 보세요.
02

제작대에 부품 놓기

  1. 예제 아래 내가 직접 만들어보기 또는 왼쪽 아래 부품함을 누르세요.
  2. 검색칸에 LED나 저항처럼 부품 이름을 입력하세요.
  3. 목록의 부품을 제작대로 끌어다 놓으세요. 부품을 선택한 뒤 E로 왼쪽, R로 오른쪽 90° 회전, T로 좌우 반전할 수 있어요.
03

핀 두 개를 연결하기

  1. 부품 가장자리의 작은 원이 핀이에요. 마우스를 올려 이름을 확인하세요.
  2. 첫 번째 핀을 클릭한 뒤 다른 핀을 클릭하면 선이 생겨요. 연결을 취소하려면 Esc를 누르세요.
  3. 아래 색상 버튼으로 새 선의 색을 고를 수 있어요. 자동으로 연결은 핀 역할에 맞춰 색을 선택해요.
04

화면 이동과 편집

  • 빈 곳 드래그로 화면을 옮기고 마우스 휠로 확대·축소해요.
  • 부품 드래그로 부품을 옮겨요. Shift를 누르고 빈 곳에서 드래그하면 여러 부품을 선택해 함께 움직일 수 있어요.
  • 선이나 부품을 선택하고 Delete로 삭제해요. Ctrl+Z로 되돌리고 Ctrl+Y로 다시 실행해요.
05

가상 전원 켜기

  1. LED 예제를 연 뒤 위쪽 가상 전원 OFF 버튼을 눌러 켜세요.
  2. 왼쪽 아래 보드 핀 출력에서 연결된 GPIO의 상태를 바꿔 보세요.
  3. LED 상태를 확인한 뒤 버튼을 다시 눌러 가상 전원을 끄세요.
06

저장하고 다시 열기

  1. 파일 → 저장을 누르면 프로젝트 파일이 다운로드돼요.
  2. 복사본을 만들려면 파일 → 다른 이름으로 저장을 선택하세요.
  3. 파일 → 외부에서 가져오기 또는 왼쪽 메뉴의 최근 프로젝트에서 저장한 파일을 여세요.
07

AI 에이전트에 질문하기

  1. 오른쪽 채팅창에 만들고 싶은 회로나 확인할 문제를 적어요.
  2. 현재 회로도 함께 보려면 현재 배선 함께 보내기를 선택하세요.
  3. 연결을 바꾸려면 도움말 → 에이전트 연결 설정을 여세요. DB와 Copilot 연결을 함께 확인해요.
