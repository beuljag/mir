# 미르 부품 2D 그림 제작 안내

미르의 2D 배선 화면에 보이는 **보드·모듈·소자 그림(SVG)** 을 만들기 위한 문서입니다.
이 문서를 통째로 다른 AI(ChatGPT, Gemini, Copilot 등)에게 주고 아래 "AI에게 줄 요청문"을 붙여 넣으면 됩니다.

---

## AI에게 줄 요청문 (복사해서 사용)

```
아래 문서의 "부품 목록"에 있는 부품마다 SVG 파일을 하나씩 만들어 줘.
- 각 부품의 "캔버스 크기"를 viewBox와 width/height로 정확히 써.
- "핀 위치" 표의 좌표에 실제 부품처럼 핀 헤더 구멍/패드/다리를 그려. 핀 좌표가 1px도 어긋나면 안 돼.
- "공통 규칙"을 모두 지켜.
- 한 번에 한 부품씩, 파일 이름과 SVG 코드만 코드 블록으로 줘.
```

---

## 공통 규칙

### 파일
- 형식: **SVG** (권장). PNG도 되지만 확대하면 흐려집니다.
- 파일 이름: 부품 id + `.svg` (예: `esp32-devkitc.svg`)
- 크기: 부품마다 정해진 **캔버스 크기**를 그대로 사용
  `<svg xmlns="http://www.w3.org/2000/svg" width="184" height="382" viewBox="0 0 184 382">`
- 좌표계: 왼쪽 위가 (0, 0). x는 오른쪽, y는 아래로 커집니다.

### 그리면 안 되는 것
- `<script>`, 외부 링크(`href="http://..."`), 외부 이미지, 웹폰트 → **금지**
- `<text>` 로 핀 이름 쓰기 → 프로그램이 직접 씀 (겹쳐서 지저분해짐)
- 부품 이름 크게 쓰기 → 프로그램이 위쪽 가운데에 `U1 · ESP32 DevKitC V4` 처럼 직접 씀
- 그림자·광택 그라데이션 과하게 쓰기 (작게 보면 뭉개짐)

### 프로그램이 그림 위에 덧그리는 것 (비워 둘 자리)
| 위치 | 프로그램이 그리는 것 | 그림에서 할 일 |
|---|---|---|
| 위쪽 가운데, y = 0 ~ 28 | 부품 이름 (흰 글자 또는 검은 글자) | 단색 바탕으로 비워 두기 |
| 각 핀 좌표 | 지름 10px 동그라미 (연결 지점) | 그 자리에 핀 헤더/패드/다리 끝을 그리기 |
| 왼쪽 핀에서 오른쪽으로 10~60px | 핀 이름 글자 (작은 고정폭 글씨) | 복잡한 무늬 피하기 |
| 오른쪽 핀에서 왼쪽으로 10~60px | 핀 이름 글자 | 복잡한 무늬 피하기 |
| 아래쪽 y = 높이-18 ~ 높이 (보드 제외) | 상태 글자 ("측정 중", "딸깍!") | 단색 바탕으로 비워 두기 |

- 바탕색이 **어두운 부품**(파란·검은·초록 PCB)이면 프로그램은 흰 글자를, **밝은 부품**이면 검은 글자를 씁니다. 바탕을 한 가지 톤으로 유지해 주세요.
- 화이트/블랙 모드가 둘 다 있으므로, LED·저항처럼 **PCB가 없는 소자**는 바탕을 투명하게 두세요.

### 스타일
- 실제 부품 사진을 보고 단순화한 **플랫 일러스트** (선 1~1.5px, 둥근 모서리 4~8px)
- 실물 색 그대로: ESP32 DevKitC는 검정/남색 PCB + 은색 실드, 라즈베리파이는 초록 PCB, 릴레이 모듈은 파란 PCB + 파란 릴레이 상자 등
- 칩 위의 글자(예: `ESP32-WROOM-32`, `SRD-05VDC`)는 7~9px 크기로 작게만
- 저항 색띠는 실제 값대로 (220Ω = 빨강·빨강·갈색·금색, 10kΩ = 갈색·검정·주황·금색)
- 다이오드는 띠가 **K(캐소드) 쪽**, LED는 긴 다리가 **A(애노드)**

## 만든 그림을 넣는 방법

1. SVG 파일을 `parts/` 폴더(기본 부품) 또는 `내 부품 폴더`(부품함 ⋯ 메뉴 → 내 부품 폴더 열기)에 넣습니다.
2. 같은 폴더의 부품 JSON에 한 줄 추가합니다.
   ```json
   "image": "esp32-devkitc.svg",
   ```
3. 프로그램을 다시 켜거나 부품함 ⋯ → **부품 다시 불러오기**를 누릅니다.

- 그림이 없거나 파일을 못 찾으면 프로그램이 기본 그림으로 그립니다.
- 새 부품을 `+ 파일`로 추가할 때 JSON과 같은 폴더에 그림이 있으면 함께 복사됩니다.
- 핀을 추가·삭제하거나 이름을 바꾸면 **캔버스 크기와 핀 위치가 바뀝니다.** 그때는 아래 "새 부품의 크기 계산법"으로 다시 계산하세요.

## 앱 아이콘

| 파일 | 크기 | 위치 |
|---|---|---|
| `icon.png` | 512 × 512 이상, 정사각형, 배경 투명 가능 | `build/icon.png` |
| `icon.ico` (선택) | 256 × 256 포함 | `build/icon.ico` |

- 넣으면 창 제목줄, 작업 표시줄, `npm run dist`로 만든 `.exe` 아이콘에 쓰입니다.
- 작은 크기(16~32px)에서도 알아볼 수 있게 단순하게 만드세요.

## 새 부품의 크기 계산법

부품 JSON의 핀 목록으로 아래처럼 계산합니다. (프로그램 `renderer/canvas.js`의 `layoutPart`와 같은 계산)

```
왼쪽 핀 수 = L, 오른쪽 핀 수 = R, 위쪽 핀 수 = T, 아래쪽 핀 수 = B
가장 긴 핀 이름 글자 수 = n
보드인가? (behavior.kind == "board")

sideW  = n × 7 + 14
titleW = 부품 이름 글자 수 × 7.5 + 64
topW   = max(T, B) × 44 + 20
너비 W = max( 보드면 170 아니면 110,
              (L>0 이고 R>0) ? sideW×2+30 : sideW+50,
              titleW, topW )

위여백 = T>0 ? 18 : 0
행 수  = max(L, R, 1)
높이 H = 30 + 위여백 + 행 수 × 18 + 10 + (B>0 ? 18 : 0) + (보드면 0 아니면 18)

왼쪽 i번째 핀(0부터)  : x = 0, y = 30 + 위여백 + i × 18 + 9
오른쪽 i번째 핀       : x = W, y = 30 + 위여백 + i × 18 + 9
위쪽 i번째 핀         : x = W / (T+1) × (i+1), y = 0
아래쪽 i번째 핀       : x = W / (B+1) × (i+1), y = H
```
