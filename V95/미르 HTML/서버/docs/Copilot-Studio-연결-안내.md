# Copilot Studio 에이전트를 프로그램에 연결하기

현재 미르는 새 에이전트용 **웹사이트 연결**과 클래식용 **Direct Line 연결**을 지원합니다.

## 현재 PC의 기본값: 서버 API (.env)

상위 Python 프로젝트의 `.env`에서 `COPILOT_DIRECT_LINE_SECRET=` 뒤에 비밀 키를 넣습니다.
미르는 `.env`의 배선 API 키로 자동 연결합니다. **연결 설정 → 서버 API → 연결 테스트**를 실행합니다.
Direct Line 비밀 키는 브라우저에 입력하지 않습니다. 서버가 대신 Microsoft를 호출합니다.
자세한 안내는 상위 프로젝트의 `DIRECTLINE_SETUP.md`를 참고하세요.

## 대체 연결: 에이전트 웹사이트

1. 미르의 **연결 설정 → 에이전트 웹사이트**를 선택합니다.
2. Copilot Studio에서 제공한 `https://copilotstudio.microsoft.com/environments/.../bots/.../canvas?...` 링크를 넣고 저장합니다.
3. 오른쪽 Microsoft 웹 채팅에서 직접 설계를 요청합니다.
4. 저장된 회로 ID를 **배선 API · DB**에 넣어 불러옵니다.

이 PC는 제공받은 중앙 설계 에이전트 링크를 기본값으로 설정했습니다.
실제 삽입 화면은 같은 에이전트의 `/webchat` 경로로 열어 안내 페이지 없이 채팅만 표시합니다.
**에이전트 웹사이트 열기**는 원래 링크를 별도 브라우저에서 엽니다.
웹 채팅의 답변을 미르가 자동으로 읽거나 현재 배선을 자동 전송하지는 않습니다.

`You don't have access to talk to this bot`가 표시되면 링크의 화면 표시와 별도로 대화 권한 확인이 필요합니다.
평소 사용하는 Microsoft 계정으로 해당 웹사이트에서 답변이 오는지 확인하세요.
연결 테스트는 URL 형식만 검사하며 권한이나 도구 호출 성공을 뜻하지 않습니다.
API 키는 웹사이트 URL에 넣지 않습니다.

아래 Direct Line 방법은 **클래식 에이전트용**입니다. 새 에이전트 환경에는 해당 메뉴가 없을 수 있습니다.

## 0. 공통 준비

1. https://copilotstudio.microsoft.com 에서 에이전트를 엽니다.
2. **개요 > 지침**에 `Copilot-Studio-지침.md`의 내용을 붙여 넣습니다.
3. 오른쪽 위 **게시(Publish)** 를 누릅니다. 게시하지 않으면 바뀐 내용이 프로그램에 반영되지 않습니다.

## 방법 A. Direct Line 비밀 키 (웹 채널 보안)

1. 에이전트 **설정(Settings) > 보안(Security) > 웹 채널 보안(Web channel security)** 으로 갑니다.
2. **비밀 1(Secret 1)** 의 `복사`를 누릅니다.
3. 프로그램 오른쪽 위 **⚙ → "Direct Line 비밀 키"** 를 고르고 붙여 넣은 뒤 **연결 테스트**를 누릅니다.

- 키는 이 PC에만 암호화되어 저장됩니다. 키를 다른 사람에게 보내거나 깃허브에 올리지 마세요.
- 메뉴가 없다면 에이전트 유형과 조직 정책을 확인하세요. 메뉴 부재만으로 관리자 차단이라고 판단하지 않습니다.
- 브라우저 모드에서는 비밀 키 입력을 지원하지 않습니다. 이 방법은 Electron 앱용입니다.

## 방법 B. 토큰 끝점 URL (인증 없음)

1. **채널(Channels) > 모바일 앱(Mobile app)** 에서 **토큰 끝점(Token Endpoint)** URL을 복사합니다.
2. 프로그램 **⚙ → "토큰 끝점 URL"** 에 붙여 넣고 **연결 테스트**를 누릅니다.
3. 인증 정책에 따라 추가 구성이 필요할 수 있습니다. 연결을 위해 기존 인증을 임의로 끄지 마세요.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| `Direct Line 오류 403` | 비밀 키가 틀렸거나 다시 생성됨 → 새로 복사 |
| `토큰 발급 실패 (401/403)` | 인증 없음으로 게시되지 않음 → 인증 설정 확인 후 게시 |
| `에이전트 응답 시간이 초과되었습니다` | 에이전트가 오래 생각함/오류 → Copilot Studio 테스트 창에서 같은 질문 해 보기 |
| 답은 오는데 그림이 안 그려짐 | 지침의 JSON 형식이 빠짐 → 지침을 다시 붙여 넣고 게시 |
| "부품함에 없는 부품" 경고 | 에이전트가 목록에 없는 id를 씀 → 부품 JSON 추가 또는 지침의 [부품 목록] 규칙 강조 |

## 데모 모드

연결 전에도 **데모 모드**로 정해진 예시(밸브 제어, 온도→OLED, LED, 라즈베리파이 LED)를 체험할 수 있습니다.
