# 미르 HTML V92

**미르 HTML.html**을 더블클릭하면 제작대가 바로 열려요. 같은 폴더의 CSS, JavaScript, assets와 docs도 함께 보관해 주세요.

AI와 DB는 도움말의 에이전트 연결 설정에서 연결해요. HTML 직접 실행에서는 공유 서버를 선택하고 서버 주소와 배선 API 키를 입력하세요. 로컬 서버도 http://127.0.0.1:8000 주소로 연결할 수 있어요. 키는 미리 포함하지 않았어요.

서버가 파일 출처의 접속을 허용해야 직접 실행한 HTML에서 AI와 DB를 연결할 수 있어요. 서버의 접속 허용 설정은 관리자가 확인해야 해요. 기존 HTML 실행기를 이용하면 기존 서버 연결 방식을 사용할 수 있어요.

기존 HTML 실행기도 계속 사용할 수 있어요. 이전 버전 실행기가 켜져 있으면 닫고 V92 실행기를 열어 주세요.

화면 구조는 HTML, 모양은 CSS, 동작은 JavaScript로 나뉘어 있어요. entry.js와 assets를 수정한 뒤 실행 JavaScript를 다시 만들려면 이 폴더에서 다음 명령을 실행해요.

```
npx --yes --package=esbuild esbuild entry.js --bundle --format=iife --platform=browser --outfile=미르.js
```
