미르 HTML

내 부품을 추가하는 방법

  1. 부품함 메뉴에서 부품 양식 파일 저장을 눌러 JSON 양식을 받으세요.
  2. 부품의 id, name, pins를 작성하세요. ID에는 소문자, 숫자, 하이픈을 쓸 수 있어요. 핀 ID는 부품 안에서 서로 달라야 해요.
  3. 그림을 넣을 때는 image에 SVG 또는 PNG 파일 이름을 적으세요.
  4. 부품함의 + 파일에서 JSON과 그림 파일을 함께 선택하세요.

추가한 부품은 같은 브라우저의 미르 HTML에서 다시 사용할 수 있어요. 원본 JSON과 그림은 따로 보관해 주세요.
