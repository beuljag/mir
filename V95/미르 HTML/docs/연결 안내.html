AI와 배선 DB 연결하기

제작대를 열고 도움말 → 에이전트 연결 설정에서 DB와 Copilot AI를 확인하세요. DB가 준비되면 AI 설정을 완료하기 전에도 회로 저장과 불러오기를 사용할 수 있어요.

공유 배선 서버로 연결

  1. 미르 HTML 실행.cmd를 실행하세요. Node.js 20 이상이 필요해요.
  2. 도움말 → 에이전트 연결 설정에서 공유 서버를 선택한 뒤 관리자에게 받은 HTTPS 주소와 배선 API 키를 입력하세요.
  3. 연결 확인 및 적용을 누르세요. 배선 API 키는 탭을 닫거나 새로고침하면 다시 입력해야 해요.

Copilot Direct Line 비밀 키는 서버 관리자가 서버의 .env에서 설정해요.

이 PC에서 배선 서버 실행

  1. 서버 폴더에서 터미널을 열고 python -m pip install -r requirements.txt를 실행하세요.
  2. .env.example을 복사해 .env로 저장하고 CIRCUIT_API_KEY와 COPILOT_DIRECT_LINE_SECRET을 설정하세요. 배선 API 키는 24자 이상이어야 해요.
  3. 같은 터미널에서 python run.py를 실행하세요.
  4. 미르 HTML 실행.cmd로 제작대를 열고 도움말 → 에이전트 연결 설정 → 이 PC의 서버를 선택한 뒤 연결 확인 및 적용을 누르세요.

자세한 Direct Line 설정은 서버 폴더의 DIRECTLINE_SETUP.md에서 확인할 수 있어요.

DB에 저장되는 배선 정보

이 폴더의 배선 서버는 지정한 선 종류와 메모까지 저장해요. 공유 서버가 이 기능을 지원하지 않으면 DB 화면에 안내가 표시돼요. 해당 서버에서는 프로젝트 파일에 선 종류와 메모를 함께 보관할 수 있어요.
