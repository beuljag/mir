# 미르 V106

- [Windows V106 EXE 다운로드](EXE/mir-V106.exe): 압축 해제나 Python 설치 없이 실행합니다.
- [미르 HTML](미르%20HTML/미르%20HTML.html): HTML 폴더 전체를 함께 보관하세요.
- [Electron 개발 소스](개발소스/Electron): V106 제작대와 튜토리얼을 포함한 Windows 실행기입니다.

빈 제작대의 **LED 튜토리얼 바로 시작**에서 부품 꺼내기·세 배선·가상 전원·GPIO HIGH/LOW를 실습합니다. 튜토리얼에는 AI 연결이나 API 키가 필요하지 않습니다. AI·DB는 기존 공유 서버가 실행되어 있어야 사용할 수 있습니다.

EXE는 HTML과 동일한 V106 제작대를 내장하고, 같은 창의 기본 닫기·프로젝트 저장 안내를 지원합니다. 실제 Python API 서버·KiCad·ngspice를 EXE 안에서 실행하는 패키지는 아닙니다. 기존 데스크톱 개발 소스는 `개발소스/기존데스크톱`에 보존합니다.

빌드와 검증 내역은 [EXE 제작 안내](개발소스/Electron/README.md)를 확인하세요.
