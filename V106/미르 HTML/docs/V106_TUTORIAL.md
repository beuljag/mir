# V106 LED 튜토리얼 복원

V105의 로컬 LED 실습을 현재 V106 웹 원본에 선택적으로 통합했습니다. V106의 키 없는 공개 서버 연결과 Railway 실행 코드는 유지했습니다.

빈 제작대의 **LED 튜토리얼 바로 시작**을 누릅니다. 보드(ESP32)·220Ω 저항·LED를 직접 부품함에서 꺼내고 세 선을 연결한 다음, 가상 전원을 켜고 GPIO26을 HIGH/LOW로 바꾸는 순서입니다. 부품 소개, 단계별 애니메이션, 고스트 핀 연결, 전원 강조, 실습 종료를 지원합니다. 튜토리얼 시작에는 AI 요청·로그인·API 키가 필요하지 않습니다.

원본 `assets/app.js`와 튜토리얼 모듈 4개, 전용 CSS를 통합하고 `npm run build`로 번들을 재생성했습니다. 다음 원본 동기화에서 튜토리얼이 빠진 앱을 감지하면 복사 전에 중단하도록 보호합니다.

이 변경은 HTML 튜토리얼 복원입니다. EXE를 재빌드한 변경이 아니며 기존 데스크톱 파일·README·운영 설정·Volume은 수정하지 않습니다. 검증 결과는 PR에 기록합니다. main 병합과 운영 배포는 이 요청에 포함되지 않습니다.
