# V106 EXE 검사

Windows 최종 휴대용 파일 `EXE/mir-V106.exe`(74,624,560 바이트)를 실제 실행했습니다. 검사일은 2026-11-16입니다. SHA-256은 `EXE/SHA256.txt`에 기록했습니다.

- 압축 파일이 아닌 최종 portable EXE의 실행과 제작대 로딩 확인.
- 네이티브 종료 브리지 확인.
- 부품함을 실제 클릭해 보드·저항·LED 추가. 부품함 폭 260px 이상 확인.
- 세 배선 연결, 가상 전원, GPIO26 HIGH/LOW, 튜토리얼 완료와 나가기 통과.
- 정상 종료 IPC로 창과 프로세스 종료 확인.
- 페이지 JavaScript 오류 없음.

숨김 검사 창의 화면 캡처는 시간 초과되어 시각 캡처 검증으로 간주하지 않았습니다. 창의 동작과 DOM 상태를 별도로 검사했습니다. 기존 숨김 검사 창이 남아 새 실행과 충돌한 경우 앱의 종료 IPC로 정리하고 새 실행에서 다시 통과했습니다.

실제 서버를 EXE에 포함하지 않습니다. 실제 AI 응답·하드웨어·다른 Windows PC·설치 프로그램은 이번 EXE 검사 범위가 아닙니다. HTML의 PC·모바일 튜토리얼과 Node 32건 회귀 검사는 앞선 V106 수정에서 통과했습니다. EXE는 코드 서명하지 않았습니다.

V95 폴더 제거 전에 개발 소스를 `V106/개발소스/기존데스크톱`에 보존했습니다. V95 실행 파일을 V106으로 이름만 바꾼 것이 아니라 현재 V106 HTML로 새로 빌드한 실행 파일입니다.
